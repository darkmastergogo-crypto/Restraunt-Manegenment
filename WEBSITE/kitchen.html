Request notification sound

Enable Request alerts on each staff device. For locked-screen sound, allow notifications and sound for this website/browser in the phone settings, turn up notification volume, and check Do Not Disturb and battery/background restrictions.

New orders use a bright three-note chime; waiter calls use a separate ding-dong. Enable each sound separately in Pending Orders and Requests. Both custom sounds work only while this page is open and visible. Background notifications use the phone's chosen system sound. A website cannot force maximum volume, bypass silent mode or guarantee delivery when the browser is closed or force-stopped.

The test checks this device's notification display/sound, not the Supabase sender or closed-browser delivery. On iPhone, web push requires an installed Home Screen web app on supported iOS.
