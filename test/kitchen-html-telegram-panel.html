Telegram Alerts

Get instant Telegram messages for new orders, waiter calls, song requests, and stock alerts. Create a bot with @BotFather, add the bot to each person's Telegram, then add them as recipients below.

Recipients

Each person or group has a chat ID and a role. The bot must be started (for private chats) or added to the group before messages will arrive.

Add recipient

To find a chat ID: add @userinfobot to the group and type /start — it replies with the ID. For a personal chat, message @userinfobot directly.
