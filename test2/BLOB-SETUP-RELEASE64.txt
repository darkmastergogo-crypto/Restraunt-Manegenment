RELEASE 64 — VERCEL BLOB ADMIN-ONLY IMAGE UPLOADS

1. Deploy the WEBSITE folder as your Vercel project root (or deploy its contents as the root).
2. Connect your PUBLIC Vercel Blob store to this SAME Vercel project.
3. Set these SERVER environment variables in the Vercel project:
   BLOB_READ_WRITE_TOKEN = token from the connected public Blob store
   SUPABASE_URL = same Supabase project URL as config.js
   SUPABASE_ANON_KEY = same PUBLIC/anon key as config.js
   Never put BLOB_READ_WRITE_TOKEN in config.js or other browser files.
4. Deploy again after adding environment variables.
5. Sign in as admin and complete TOTP verification. Upload a dish photo, then replace it.
   Confirm that each upload produces a different public Vercel Blob URL.
6. Verify manager image uploads are rejected (403), and customers can view images.
7. Existing Supabase images are not migrated; they remain readable.
8. Supabase RLS and RPC permissions must continue protecting menu writes. The Blob
   endpoint verifies admin role + TOTP using restaurant_admin_auth_status.
9. Images are limited to 1 MB and use the existing browser compression.
10. Vercel Hobby is restricted for commercial use; use a suitable plan for paid customers.

NOTE: Uploaded Blob objects are not automatically deleted on menu removal/replacement.
Review storage periodically and implement a separately authorized cleanup process.
